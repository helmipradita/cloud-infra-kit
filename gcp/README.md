# Google Cloud Platform Blueprint (Roadmap)

This module will contain starter Infrastructure as Code (IaC) templates for Google Cloud Platform (GCP):

## Planned Architecture
* **Networking**: Custom VPC network, subnets, and Cloud NAT.
* **Compute**: `e2-micro` Always Free Compute Engine instance.
* **Automation**: Ansible playbook for Swap, SSH hardening, and Docker CE.

*Status: Under development.*
