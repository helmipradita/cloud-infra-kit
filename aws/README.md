# AWS Infrastructure Blueprint (Roadmap)

This module will contain starter Infrastructure as Code (IaC) templates for Amazon Web Services (AWS):

## Planned Architecture
* **Networking**: Custom VPC with public subnets and Internet Gateway.
* **Compute**: EC2 instance (`t4g.small` or `t3.micro`) with baseline Security Groups.
* **Automation**: Ansible playbook for Swap, SSH hardening, and Docker CE.

*Status: Under development.*
