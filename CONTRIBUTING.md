# Contributing to cloud-infra-kit

Contributions are welcome! This repository aims to provide clean, minimal, and beginner-friendly Infrastructure as Code (IaC) templates for various cloud providers.

## Principles
1. **Zero Secret Policy:** Never commit credentials, `.env` files, or private keys.
2. **KISS Principle:** Keep templates simple and avoid unnecessary abstractions.
3. **Reproducibility:** Infrastructure must be testable with clean commands.

## Getting Started
1. Fork the repository.
2. Create your feature branch (`git checkout -b feat/add-new-provider`).
3. Commit with Conventional Commits.
4. Open a Pull Request.
